# Settings scroll and shared dropdown follow-up — 2026-11-02

This follow-up starts at `8c2a1c899f74f9d310c2dbb935ea3e1d168b599d`
on `2.1LTS`. It addresses the user's remaining settings scroll stutter,
one-sided arrow animation and inconsistent settings/course dropdown styling.

## Rendering and input changes

- Settings fields now live in one content window inside a native clipped
  viewport. Steady scrolling moves that content window; individual fields keep
  their local geometry and no longer receive changing window regions. The title
  and footer stay outside the viewport. Command, owner-draw, color and keyboard
  handling continue to reach the settings window through the nested hierarchy.
- The settings root no longer uses `WS_EX_COMPOSITED`. `WS_EX_LAYERED` is enabled
  for opacity transitions and removed at full opacity, followed by one repaint.
  Reopening a closing cached window still reverses its current animation.
- Settings dropdowns and the main course selector use the same
  `AttendanceThemedPopupMenu` class as Tools. This includes the surface, rounded
  corners, item layout, hover, scrolling, scrollbar, clipping and close animation.
  Dropdown panels align to their field and are at least as wide as the field;
  the current selection has a check mark and is initially scrolled into view.
- Closed combo fields use the shared rounded control drawing without a separate
  rectangular arrow compartment. The native combo retains its item data and
  selection notifications; its native list window is not shown.
- Opening and closing arrows use the same continuous animation channel.
  The custom menu message loop dispatches animation ticks during expansion,
  and the arrow starts returning as soon as the popup starts closing.
- Arrow keys, Home/End, Page Up/Down, Enter, Escape, F4, Tab and prefix typing
  are supported. A deferred font-list refresh runs after the selected font has
  been committed. Popup ownership follows the anchor's top-level window.
- Cached row offsets and a single item-animation sample avoid quadratic layout
  work and repeated animation locks in long font menus.

Microsoft documents removing the layered style and repainting once the window
is fully opaque in [Using Layered Windows](https://learn.microsoft.com/en-us/windows/win32/winmsg/using-windows#using-layered-windows).
