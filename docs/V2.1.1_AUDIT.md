# AttendanceApp 2.1.1 LTS implementation and validation audit

> Historical record: this build was withdrawn to draft after UI regressions were reported. Current repair work and acceptance are recorded in [V2.1.1_UI_REPAIR.md](V2.1.1_UI_REPAIR.md).

Date: 2026-11-01. Branch: `2.1LTS`. Source: the migrated Attendance Project 2.1 LTS directory. This record describes this maintenance revision; the 2.1.0 and 2.0.4 audits retain their historical results.

## Implemented

- Removed Apply. Settings retains native controls, a fixed title/footer, measured content layout, continuous pixel scrolling and inline save/retry feedback. Scroll frames reuse cached geometry instead of measuring the form again. The FPS field is committed on Enter, focus loss or Close.
- Atomic reset writes default preferences before applying them. Failed reset preserves the previous file and live settings. Runtime fonts, language, shortcuts, grid, filter results and autosave timing are refreshed together.
- Cached settings restart their entrance, reverse an in-progress close and distinguish each close completion by a serial. Obsolete animation messages are discarded when a window's animation state is removed. Hidden prewarming and language refresh remain hidden.
- Shared cubic Bezier motion drives paper clipping, direction-aware popup reveal and bounded 20 ms item staggering. Native dropdowns keep their selection protocol and use at most one non-interactive exit surface. Command menus share measured rows, rounded surfaces, shadows and stable hit geometry.
- Wrapped action labels and titles, consistent spacing/targets, measured card labels and fixed-width numeric cells improve the existing theme without changing its palette.
- Save, import, backup and report work use the bounded worker queue. Workers operate on snapshots; the UI commits document replacements and checks save generations/revisions. Slow tasks show a delayed spinner, successful actions show a check and optional bounded particles, and failures never become success animations.
- Workbook parsing has a pure entry point returning the active-course index. CSV filtering, HTML statistics and PowerPoint slide assembly use captured ranges/dates/languages on workers. A scoped thread-local translation context avoids changing live preferences.
- Report callbacks retain their original owner window and generation. Retired windows do not receive another task's callback. Queue rejection restores import input state without replacing data.
- Fourteen maintenance messages were translated for all 20 supported languages. Version metadata is 2.1.1; V6 and settings-file keys remain compatible.
- The build wrapper detects CMake configurations copied from another source directory and removes only the current project's validated generated configuration before configuring again.

## Defect review

| Severity | Reproduction or risk | Correction and evidence |
| --- | --- | --- |
| Medium, functional | Reset cannot remove/write its settings path, but old code still changes live defaults. | Atomic default write precedes state mutation; injected path failure and settings reload are regression cases. |
| Medium, UI/function | Footer actions are below all settings options; Apply duplicates immediate commits. | Fixed measured footer and removal of Apply; all-language native geometry cases. |
| Medium, UI/function | Cached opening/closing state can survive a previous opening; repeated test runs exposed an intermittent close completion failure. | Independent hide lifecycle, close serials, stale-message rejection and 30-cycle regression. |
| Medium, UI/function | Settings scroll jumps; dropdown and menu rows use inconsistent motion and coordinates. | Cached pixel-position updates, shared clipping, fixed hit coordinates and cubic motion; visual acceptance remains separate. |
| Medium, functional | A shared report owner can redirect callbacks after another owner queues work or a window disappears. | Per-job owner/generation; retired-owner regression. |
| Medium, functional | Parsing a legacy file for migration can alter the global loaded-course index. | Pure decoder; active-index isolation and asynchronous import regressions. |
| Medium, functional | Expensive file/report preparation blocks the UI; a late save can otherwise clear newer edits. | Immutable background work and revision-aware save completion; snapshot/thread and dirty-state regressions. |
| Medium, functional | Advanced-search setting changes do not immediately refresh the existing result set. | Refresh results/statistics on the setting change. |
| Minor, UI | Fixed text rows, clipped translations and proportional numeric widths produce inconsistent layout. | Measured/wrapped labels, balanced titles and stable digit cells; settings geometry is checked for every supported language. |
| Build | A copied CMake cache still points at Attendance Project 2.0. | Source-root mismatch was observed on the first build; the repaired wrapper configured and built the LTS directory. |

No claim is made that every possible defect has been found. Existing six-state, model, history, file-format, storage and report cases remain in the regression suite. Desktop-only issues cannot be closed by off-screen geometry alone.

## Environment and limits

- Computer Use's required `node_repl` runtime was not exposed in this session. No alternate PowerShell UI automation was used. No current desktop screenshots, animation recording or subjective visual acceptance are claimed.
- All-language native geometry tests are not a native-speaker review. The 100%/150%/200% Windows scaling matrix, actual pointer interaction with animated popups, and high-speed recording of the reported brief flashes remain unverified.
- Clean-machine GUI startup without development tools, physical power loss/disk-full behavior and registry association installation require separate environments/actions.
- Tests set `ATTENDANCEAPP_DATA_DIR` to the marked project-local test root. Real AppData and attendance files are excluded from test cleanup. The historical GB-scale growth has not been attributed to a proven cause.
- Publication targets only `2.1LTS`, using tag `v2.1.1` and Release title `v2.1.1 LTS`; `main` is not updated. The pre-existing deletion of `src/main.cpp.backup-combo-theme` is excluded from the maintenance commit. Final publication identifiers are recorded with the delivered validation JSON.
