# 2.1.1 LTS UI repair — 2026-11-02

The [settings/dropdown follow-up](V2.1.1_SETTINGS_POPUPS.md) supersedes the
initial settings scrolling and native dropdown implementation described below.
Its separate repair-2 package records the later verification results.

This repair targets `2.1LTS` from `2e062692d5a052649edbb847ad77602a71caf1b2`.
The withdrawn 2.1.1 release remains a draft. The ordinary development checkout,
`main`, release tag and withdrawn ZIP are outside this local repair.

## Corrections

| Surface | Failure and correction |
| --- | --- |
| Main layout | The table overlapped composer labels. Geometry now reserves measured label, editor, action and footer heights before positioning controls. Content bounds grow for long translations and large fonts, and scrolling is clamped after the bounds are known. |
| Main header | Subtitle text could extend under the course selector. Both title and subtitle stay inside the header text column; the course action follows the dropdown height. |
| Main wheel input | Wheel events were interpreted as `SB_LINEUP`, so scrolling downward could not reach bottom actions. Wheel deltas now take precedence over scrollbar commands, high-resolution deltas retain smaller increments, and horizontal wheel direction follows Windows semantics. Table wheels scroll records first and reach the outer form at an edge; inputs and closed dropdowns forward wheels to the outer form. |
| Statistics cards and buttons | Eight nested card highlights produced beveled edges. Cards now have a flat surface and subtle outline; regular buttons share neutral styling, with a danger tint for destructive actions. Rounded shapes are smoothed, and particle clipping follows the same button radius. |
| Settings scrolling | Repeated ticks resized every control, reset every clipping region and invalidated the body. Applied positions and regions are cached, move-only frames use `SWP_NOSIZE`, and edit metrics update on size, frame, font or native-theme changes. Settled reveal ticks do not move or invalidate fields. |
| Settings input alignment | The numeric FPS field ignored the multiline formatting rectangle, and native theme changes reset edit padding. Numeric fields now accept the same formatting as other single-line inputs, theme refreshes restore it, and the FPS unit is vertically centered. |
| Settings wheel input | A closed combo consumed wheel input and silently changed its value. The wheel now scrolls the form until the dropdown is open. |
| Language and density | Language changes now recompute main geometry. Density updates refresh dropdown metrics while retaining the title/subtitle font hierarchy. |
| Popup rendering | Popup paints are queued rather than forced synchronously per tick. Completed clipping regions are reused, with window dimensions included in the cache. |
| Menu scrollbar | Scrollbar release could activate an unrelated command, and the thumb did not drag. Thumb dragging and page clicks now scroll without selecting or closing a menu. |
| Statistics chart | Fixed dimensions clipped the last status, long labels and counts. The chart now measures columns and all six rows, wraps its title, sizes within the monitor work area and supports overflow scrolling. All bars reach their full value; the close transition applies actual opacity. |
| Quick roll call | Numeric painting treated a two-line progress value as one line. Stable digit rendering now preserves line breaks and nonnumeric text runs. Course, lesson, student, status, notes, actions and hints use measured geometry; overflow and keyboard focus remain reachable. |
| Input and message dialogs | Fixed prompt/action sizes clipped long text. Prompts and actions are measured, and long explanatory text is selectable and scrollable in a read-only control. |
| Searchable chooser | Buttons now use the shared theme; translated labels are measured. Filtering preserves a surviving selection and skips redundant updates. Long items have horizontal scrolling. |
| Settings persistence | `CaptureSettings` omitted the font, default save directory and six shortcuts. Saving and reloading now preserve every preference. |
| Windows settings files | CRLF line endings and a UTF-8 BOM corrupted language, font and numeric parsing. The loader normalizes these file markers before reading values. |
| Animation presets | Standard motion truncated particle and elapsed-time scroll lifetimes. These channels now finish correctly. Off mode clears effects and still repaints immediate control-state changes. |
| Keyboard navigation | Tab inserted whitespace into main inputs, actions were not tab stops, and Enter did not activate focused buttons. The main form now has a visual tab order, rejects literal tabs in single-line fields, activates buttons once with Enter, and scrolls focused controls into view in both directions. |
| Process exit | Animation cleanup discarded `WM_QUIT`, because `PeekMessage` returns it even with an application-message filter. Cleanup now reposts the quit message and preserves its exit code. Worker joins and drawing-resource cleanup follow complete child-window destruction. |
| Operation feedback | A fixed-height notice clipped messages and continued repositioning/repainting after its animation settled. Notice geometry follows measured text, and static feedback uses a slower timer without repeated identical placement. |

The quit-message behavior is documented in [Microsoft's PeekMessage reference](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-peekmessagew).

## Validation

The regression suite exercises 540 main layouts per run (20 languages, three text
scales, three densities, three window sizes), 360 settings layouts, 60 roll-call
and chart language/scale combinations, menu thumb/page input, multiline numeric
painting, long dialogs, settings round trips, BOM/CRLF, tab order, Enter activation,
numeric input alignment after native theming, combo selection notifications, focus visibility,
animation lifetimes and quit-message preservation. Existing V1–V6, six-state,
history, backup, report and background-job cases remain included.

Maintained localization checks cover 31 feature, 23 settings and 14 maintenance
keys in 20 languages, plus 274 Hong Kong call-site keys. Three previously skipped
Hong Kong messages were added after the checker learned adjacent C++ literals.

Three final consecutive regression runs passed, using 129,968, 129,966 and 129,966
bytes of test data. CMake with native analysis and direct MSVC builds both passed;
both binaries report 2.1.1 and contain 1,134,080 bytes. Native analysis reports
contain no defects. Parser, architecture, localization and generated-catalog
consistency checks passed.

Actual Computer Use checks covered Chinese/dark/standard and German/light/large/
spacious main windows, main Tab/Enter activation, settings top and bottom with a
fixed footer and aligned FPS field, Courses/Tools/Delete menus, popup wheel and
Escape, wrapped command input and confirmation dialogs, the searchable lesson
chooser, six visible chart rows, roll-call progress and missing-note validation,
and the native CSV save picker with a successful 24-record export. The repaired
main wheel reached the bottom and returned to the top; the table scrolled records
while keeping the outer form still. Both build paths started and exited normally
with exit code 0. Final screenshots and exact binary hashes accompany the separate
local repair candidate; the withdrawn ZIP was not replaced or uploaded.

The Computer Use wrapper activates the main window before input, which prevented
reliable keyboard targeting and dropdown choice in some owned windows. Native
window tests cover those selection notifications, six-state updates, notes and
theme-transition states. No high-speed flash recording, alternate system-DPI
matrix, clean-machine startup or complete native-speaker translation review is
claimed. Settings positioning averaged 2.8–5.3 ms per update in the final three
runs, compared with about 22.5 ms in the initial local reproduction; this measures
positioning work, not end-to-end frame latency.

## Storage and preserved state

Test payloads remain isolated, under 20 MiB total and 5 MiB per file. Diagnostic
lines are read as plain strings. The summary is capped at 1 MiB and checked against
the combined 512 MiB generated-artifact budget before writing. This also fixes an
oversized diagnostic archive produced during this repair; that generated archive
was reduced from 394,771,261 bytes to a normal text summary.

The pre-existing deletion of `src/main.cpp.backup-combo-theme` is not part of this
repair. Real AppData preferences and attendance files are excluded from previews
and regression cleanup.
